# Template Selection

Read `assets/Manga_Panel_Layout_Template/template_manifest.json` first. Choose by story rhythm:

- Blank manuscript bases: use for custom layouts, covers, chapter openers, or when the user asks to avoid visible panel template constraints.
- 3-panel layouts: use for simple setup-turn-reveal pages or slow emotional beats.
- 4-panel vertical layouts: use for yonkoma, gag timing, compact repeated rhythm, or short social scenes.
- 5-panel layouts: use for balanced pages with one establishing panel, two action/reaction beats, and a final hook.
- 6-panel layouts: use for action pages, argument escalation, or pages needing a large central beat plus small reaction panels.
- 7-8 panel layouts: use only when the draft is dense and dialogue remains short.

Selection constraints:

- Use visible panel numbers as reading order.
- Prefer fewer panels when text is important.
- Prefer wider panels for establishing shots, crowds, vehicle movement, and landscape reveals.
- Prefer tall or narrow panels for entrances, isolation, falling/rising motion, or tense pauses.
- Avoid dense 7-8 panel templates when character consistency is more important than plot compression.

If a user provides a specific template image, use that template unless it conflicts with page count or story clarity.
